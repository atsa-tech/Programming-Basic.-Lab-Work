# Разбор базового синтаксиса Python

## 💻 Часть 1: REPL против файла

* **REPL** (интерактивный режим) работает как калькулятор. Его главная задача — сразу показать ответ, поэтому он **автоматически выводит** результат любого выражения.
* **Файл** (`.py`) просто выполняет заложенный алгоритм. Если вы хотите увидеть что-то на экране, интерпретатору нужно дать **явную команду** — завернуть выражение в функцию `print()`.

---

## 🔍 Часть 2: Анатомия кода

```python
course = "Python"
hours = 4.2
print(f"{course}: {hours} часов")
```

### 📋 Элементы программы:

* **Инструкции (Statements):** Это целые строки кода, выполняющие действие.
  * `course = "Python"` — создание переменной.
  * `hours = 4.2` — создание переменной.
  * `print(...)` — вызов функции для вывода текста.

* **Выражения (Expressions):** Всё, что можно вычислить и превратить в конкретное значение.
  * Переменные `course` и `hours` внутри f-строки.
  * Сама f-строка целиком после сборки.

* **Литералы (Literals):** Данные, «зашитые» прямо в исходный код.
  * Строковые: `"Python"`, `": "`, `" часов"`.
  * Числовой (float): `4.2`.

* **Идентификаторы (Имена):** Названия, которые вы придумали для переменных.
  * `course`
  * `hours`
